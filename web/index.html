상황 속에서 명령어를 익히는 실습장

왼쪽에서 시나리오를 고르세요. 진짜 리눅스 컨테이너가 만들어지고, 문제 상황을 직접 해결하면 자동으로 채점됩니다.

  1. 시작: 문제 상황이 담긴 실습 환경이 만들어져요.
  2. 실습: 오른쪽 터미널에 직접 명령어를 입력해요. 막히면 힌트를 보세요.
  3. 채점: 결과 상태를 검사해요. 정답 명령어는 하나가 아니에요.
  4. 복습: 통과한 문제는 1일 → 3일 → 7일… 간격으로 다시 풀어요.

시작 버튼을 누르면 실습 환경이 만들어집니다.
