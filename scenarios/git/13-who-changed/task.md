# 이 값을 누가 바꿨지? (blame, log -S)

어젯밤부터 결제 API 호출이 자꾸 **타임아웃**으로 실패해요. 설정 파일 `~/api/config.js` 를 보니 타임아웃이 **300ms** 예요. 원래는 **3000ms** (3초)였는데 누군가 0 하나를 빠뜨린 것 같아요.

## 목표
1. `TIMEOUT_MS` 를 **3000 → 300 으로 바꾼 커밋**의 해시를 `~/answer.txt` 에 저장하세요. (앞 7자리 이상)
2. `TIMEOUT_MS` 를 다시 **3000** 으로 고쳐서 **새 커밋**을 만드세요. 기존 기록은 고치지 마세요.
3. 끝나면 `git status` 가 깨끗해야 해요.

> 커밋한 사람에게 따지려는 게 아니에요. 왜 바꿨는지 커밋 메시지와 함께 확인하고, 같은 실수를 막을 방법을 찾으려는 거예요. 🙂

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `git blame 파일` | 줄마다 마지막으로 바꾼 커밋·사람 |
| `git blame -w 파일` | 공백(들여쓰기)만 바뀐 건 무시하고 |
| `git log -S '문자열' --oneline` | 그 문자열이 **생기거나 사라진** 커밋 (pickaxe) |
| `git log -p -- 파일` | 파일이 바뀐 내용까지 전부 |
| `git show 해시` | 커밋 하나 자세히 |
