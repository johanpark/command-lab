# 비밀번호를 커밋해 버렸다

`~/shop-api` 에서 방금 커밋을 했는데... **DB 비밀번호가 든 `.env` 파일까지 같이 커밋**해 버렸습니다! 다행히 아직 push 는 안 했어요.

## 목표
1. 저장소의 **어떤 커밋에도** `.env` 가 남아 있지 않게 하세요.
2. 마지막 커밋에 같이 들어간 **`src/orders.js` 는 커밋에 남아** 있어야 합니다.
3. 내 컴퓨터의 `.env` 파일 자체는 **지우면 안 됩니다** (앱 실행에 필요).
4. 다시는 실수하지 않게 `.env` 를 **`.gitignore` 에 추가**하고 그것도 커밋하세요.
5. 마지막엔 `git status` 가 깨끗해야 합니다.

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `git log --stat` | 커밋마다 어떤 파일이 바뀌었는지 |
| `git rm --cached 파일` | Git 관리에서만 빼기 (실제 파일은 남김) |
| `git commit --amend` | 마지막 커밋을 고쳐 쓰기 |
| `git reset --soft HEAD~1` | 마지막 커밋 취소 (변경 내용은 스테이징에 남김) |
