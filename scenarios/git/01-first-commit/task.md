# 첫 커밋 만들기

`~/my-notes` 폴더에 공부 노트를 쓰고 있습니다. 실수로 지워도 되돌릴 수 있도록 **Git으로 버전 관리**를 시작해 봅시다.

## 목표
1. `~/my-notes` 를 Git 저장소로 만드세요.
2. `notes.md` 와 `todo.md` 를 커밋하세요. 커밋 메시지는 자유.
3. `scratch.tmp` 는 **커밋하지 마세요** (임시 파일).
4. 커밋 후 `git status` 에 커밋할 변경 사항이 없어야 합니다. (scratch.tmp 가 "Untracked" 로 보이는 건 괜찮아요)

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `git init` | 현재 폴더를 Git 저장소로 만들기 |
| `git status` | 지금 상태 확인 (**가장 자주 쓰게 될 명령어**) |
| `git add 파일` | 커밋할 파일 담기 (스테이징) |
| `git commit -m "메시지"` | 담은 파일들을 하나의 버전으로 저장 |
| `git log --oneline` | 커밋 기록 보기 |
