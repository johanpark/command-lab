# 릴리스에 태그 달기 (git tag)

지난주 **1.2.0 버전**을 배포했는데 태그를 깜빡했어요. 그 사이에 다음 버전 작업 커밋이 몇 개 더 쌓였어요. 나중에 "1.2.0 은 정확히 어떤 코드였지?" 를 바로 찾을 수 있게 태그를 달아 두려고 해요.

## 목표 (`~/app` 저장소)
1. **1.2.0 을 배포한 커밋**(`VERSION` 파일을 `1.2.0` 으로 바꾼 커밋)에 **`v1.2.0`** 태그를 다세요.
   - 지금 최신 커밋(HEAD)이 **아니에요!**
   - 누가 언제 왜 달았는지 남는 **설명 붙은 태그**(annotated, `-a`)로, 메시지는 `1.2.0 릴리스`
2. 태그를 원격(`origin`)에 **올리세요.**

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `git log --oneline` | 커밋 목록 |
| `git log --oneline -- VERSION` | VERSION 파일을 바꾼 커밋만 |
| `git tag` | 태그 목록 |
| `git tag -a 이름 커밋 -m "메시지"` | 그 커밋에 설명 붙은 태그 |
| `git show 태그` | 태그 정보와 커밋 |
| `git push origin 태그이름` | 태그 올리기 (`git push` 만으로는 안 올라가요) |
| `git ls-remote --tags origin` | 원격에 있는 태그 |
