# 버그를 만든 커밋 찾아 되돌리기

`~/calculator` 는 여러 사람이 함께 만드는 계산기 스크립트입니다. 오늘 테스트를 돌려 보니 덧셈이 고장 났어요.

```
$ ./test.sh
✔ sub
✘ add: 2 + 3 = -1 (기대값 5)
```

커밋이 많아서 언제, 누가 망가뜨렸는지 모르겠어요. 이미 팀원들과 공유한(push 한) 기록이라 **기록을 지우거나 고쳐 쓰면 안 됩니다.**

## 목표
1. 덧셈 버그를 만든 **커밋의 해시**(앞 7자리 이상)를 `~/answer.txt` 에 저장하세요.
2. 그 커밋을 **`git revert`** 로 되돌리세요. (그 커밋 이후의 다른 변경은 살아 있어야 해요)
3. `./test.sh` 가 모두 통과하고, `git status` 가 깨끗해야 합니다.

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `git log --oneline` | 커밋 목록 |
| `git blame 파일` | 각 줄을 **마지막으로 바꾼 커밋**과 사람, 날짜 |
| `git log -L '/^add/,+1:파일' --oneline` | 특정 줄(add 함수)의 **변경 이력**만 |
| `git show 커밋` | 그 커밋이 바꾼 내용 |
| `git revert 커밋` | 그 커밋을 **반대로 적용하는 새 커밋** 만들기 |
