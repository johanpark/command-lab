# 망가뜨린 파일 되살리기

`~/recipes` 는 레시피 모음 저장소입니다. 오늘 정리하다가 사고를 세 번 쳤어요.

1. `kimchi.md` 를 고치다가 내용을 엉망으로 만들었다. (아직 커밋 안 함)
2. `bulgogi.md` 를 실수로 지웠다. (아직 커밋 안 함)
3. 그리고... 며칠 전 "정리" 커밋에서 지운 `bibimbap.md` 가 사실 필요했다.

## 목표
1. `kimchi.md` 를 **마지막 커밋 상태**로 되돌리세요.
2. `bulgogi.md` 를 **되살리세요.**
3. 예전 커밋에서 삭제된 `bibimbap.md` 를 **지워지기 직전 내용으로** 되살려서 **커밋**하세요.
4. 마지막엔 `git status` 가 깨끗해야 하고, 기존 커밋 기록은 그대로여야 합니다.

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `git status` / `git diff` | 무엇이 바뀌었는지 |
| `git restore 파일` | 작업 중인 변경을 버리고 마지막 커밋 상태로 |
| `git log --oneline --stat` | 커밋마다 바뀐 파일 |
| `git log --diff-filter=D --name-only` | 파일을 **삭제한** 커밋만 |
| `git show 커밋:파일` | 특정 커밋 시점의 파일 내용 보기 |
| `git restore --source=커밋 파일` | 특정 커밋 시점의 파일 꺼내오기 |
