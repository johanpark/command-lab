# 머지 충돌 해결하기

`~/website` 저장소에서 나는 `main` 브랜치에서, 동료는 `feature/new-title` 브랜치에서 같은 파일을 고쳤습니다.

## 목표
1. `main` 브랜치에 `feature/new-title` 브랜치를 **머지**하세요. 충돌이 날 거예요.
2. 충돌을 해결해서 `index.html` 의 제목 줄이 **정확히** 아래처럼 되게 하세요.
   ```html
   <h1>커맨드 연습장 - 매일 조금씩</h1>
   ```
   (동료가 바꾼 이름 "커맨드 연습장" + 내가 붙인 부제 "매일 조금씩")
3. 머지 커밋까지 완료하고, 충돌 표시(`<<<<<<<`, `=======`, `>>>>>>>`)가 남아 있으면 안 됩니다.
4. 두 브랜치의 **다른 변경 사항**(동료가 추가한 footer, 내가 추가한 nav)은 모두 살아 있어야 합니다.

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `git branch` | 브랜치 목록 (`*` 가 현재 브랜치) |
| `git merge 브랜치` | 지금 브랜치에 다른 브랜치 합치기 |
| `git status` | 충돌난 파일 확인 ("both modified") |
| `nano 파일` | 파일 편집 (`Ctrl+O` 저장, `Ctrl+X` 종료) |
| `git merge --abort` | 머지를 취소하고 처음으로 |
