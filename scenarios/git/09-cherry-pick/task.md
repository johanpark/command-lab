# 보안 패치 하나만 옮기기

`~/shop` 저장소는 이렇게 관리돼요.
- `release/1.0` : 지금 **운영 중인** 버전
- `main` : 다음 버전 개발 중 (새 기능이 잔뜩, 아직 배포하면 안 됨)

그런데 운영 버전에 보안 문제가 발견됐고, 그 수정은 이미 `main` 에 커밋돼 있어요.

## 목표
1. `main` 에서 **보안 수정 커밋 하나만** 찾아 `release/1.0` 에 적용하세요.
2. `main` 의 다른 커밋(새 기능)은 `release/1.0` 에 들어가면 **안 됩니다.** (`git merge main` 금지!)
3. `release/1.0` 에는 커밋이 **딱 하나** 늘어나야 하고, `main` 은 그대로여야 해요.

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `git log --oneline main` | main 의 커밋 목록 |
| `git log --oneline release/1.0..main` | release 에는 없고 main 에만 있는 커밋 |
| `git show 커밋` | 그 커밋이 바꾼 내용 |
| `git switch 브랜치` | 브랜치 이동 |
| `git cherry-pick 커밋` | 그 커밋 **하나의 변경**을 지금 브랜치에 새 커밋으로 적용 |
