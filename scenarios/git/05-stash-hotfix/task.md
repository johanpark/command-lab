# 작업 중에 긴급 버그 수정

`~/shop` 저장소의 `feature/coupon` 브랜치에서 쿠폰 기능을 만드는 중입니다. `cart.js` 를 반쯤 고쳤는데... 긴급 연락이 왔어요.

> "운영 중인 사이트에서 세금이 1%로 계산되고 있어요! `main` 의 `price.js` 에서 `TAX_RATE` 를 **0.1** 로 고쳐 주세요. 지금 당장요!"

## 목표
1. 작업 중인 `cart.js` 변경을 **잃지 않게** 잠시 치워 두세요. (반쯤 된 코드라 커밋하면 안 돼요)
2. `main` 브랜치에서 `price.js` 의 `TAX_RATE` 를 `0.1` 로 고쳐 **커밋**하세요. 이 커밋에는 **price.js 만** 들어가야 합니다.
3. 다시 `feature/coupon` 으로 돌아와서, 하던 작업(`cart.js` 변경)을 **커밋되지 않은 상태 그대로** 되살리세요.

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `git stash` | 작업 중인 변경을 임시 보관함에 넣고 깨끗한 상태로 |
| `git stash list` | 보관함 목록 |
| `git stash pop` | 가장 최근에 넣은 변경을 꺼내 적용 |
| `git switch 브랜치` | 브랜치 이동 |
| `git commit -am "메시지"` | 수정한 파일 모두 담아서 커밋 |
