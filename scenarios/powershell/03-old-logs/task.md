# 오래된 로그 정리하기

로그 폴더 `~/logs` 가 계속 쌓여서 디스크를 차지하고 있습니다. 정책은 **"로그는 30일만 보관"** 이에요.

## 목표
1. `~/logs` 아래(**하위 폴더 포함**)에서 **마지막 수정이 30일보다 오래된 `.log` 파일**의 개수를 `~/answer.txt` 에 저장하세요.
2. 그 파일들을 **삭제**하세요.
3. 30일 이내의 로그와 `.log` 가 아닌 파일(설정, 문서)은 **남아 있어야** 합니다.

## 써볼 명령어
| cmdlet | 하는 일 |
|---|---|
| `Get-ChildItem 폴더 -Recurse -File -Filter *.log` | 하위 폴더까지 .log 파일 찾기 |
| `(Get-Date).AddDays(-30)` | 30일 전 날짜 |
| `Where-Object LastWriteTime -lt 날짜` | 그 날짜보다 오래된 것만 |
| `Measure-Object` | 개수 세기 (`.Count`) |
| `Remove-Item -WhatIf` | **실제로 지우지 않고** 무엇이 지워질지만 보여주기 |

> 💡 삭제 명령에는 먼저 `-WhatIf` 를 붙여서 대상을 확인하는 습관을 들이세요.
