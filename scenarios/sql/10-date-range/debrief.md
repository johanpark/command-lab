# 해설

```sql
SELECT COUNT(*), SUM(amount) FROM payments
WHERE paid_at >= '2026-10-01' AND paid_at < '2026-11-01';
```

## BETWEEN 의 함정
`BETWEEN a AND b` 는 `>= a AND <= b` 예요. 끝값 `'2026-10-31'` 은 **31일 0시 정각**을 뜻해서, 그날 0시 1초부터의 결제가 전부 빠져요.

| 방법 | 문제 |
|---|---|
| `BETWEEN '10-01' AND '10-31'` | 31일이 거의 다 빠짐 ❌ |
| `BETWEEN '10-01' AND '10-31 23:59:59'` | `23:59:59.500` 같은 소수 초가 있으면 빠짐, 달마다 말일이 다름 ❌ |
| `date(paid_at) BETWEEN '10-01' AND '10-31'` | 결과는 맞지만 **인덱스를 못 씀** (열에 함수를 씌우면 느려짐) △ |
| `paid_at >= '10-01' AND paid_at < '11-01'` | 항상 맞고 인덱스도 씀 ✅ |

"시작은 포함, 끝은 다음 구간의 시작 미만" 을 **반열린 구간 `[시작, 끝)`** 이라고 해요. 날짜뿐 아니라 시간대별 집계, 페이지 범위 등 어디서나 겹치거나 빠지는 일이 없어요.

## 시간대(timezone)도 조심
DB 에 UTC 로 저장돼 있다면 한국 시간 10월 1일 0시는 UTC 로 9월 30일 15시예요. "10월 매출"이 어느 시간대 기준인지 먼저 확인하세요.
