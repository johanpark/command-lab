# 첫 컨테이너 띄우기

이 서버에는 쇼핑몰 웹 서버 **이미지** `shop-web:1.0` 이 준비돼 있어요. 이미지로 **컨테이너**를 띄워 봅시다.

> 이미지 = 프로그램 설치 파일, 컨테이너 = 그걸 실행한 것. 이미지 하나로 컨테이너를 여러 개 띄울 수 있어요.

## 목표
1. `shop-web:1.0` 으로 컨테이너를 띄우세요.
   - 이름: **`web`**
   - **백그라운드**로 실행
   - 내 서버의 **8080** 포트 → 컨테이너의 **80** 포트로 연결
2. `curl http://localhost:8080` 으로 열어 보면 **오늘의 코드**가 있어요. 그 코드를 `~/answer.txt` 에 저장하세요.
3. 예전에 쓰다 멈춰 둔 컨테이너 **`old-web`** 을 삭제하세요.

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `docker images` | 가지고 있는 이미지 |
| `docker ps` / `docker ps -a` | 실행 중인 컨테이너 / 멈춘 것까지 전부 |
| `docker run -d --name 이름 -p 8080:80 이미지` | 백그라운드(`-d`)로 실행, 포트 연결(`-p 내포트:컨테이너포트`) |
| `docker logs 이름` | 컨테이너 출력(로그) |
| `docker stop 이름` / `docker rm 이름` | 멈추기 / 삭제 |
