# 메모리 먹는 컨테이너 가두기

서버 메모리 경보가 울렸어요. 컨테이너 여러 개가 돌고 있는데, 그중 하나가 메모리를 혼자 많이 쓰고 있대요. 이 컨테이너는 **메모리 상한(limit)이 없어서** 계속 늘어나면 서버 전체를 위험하게 만들 수 있어요.

## 목표
1. **메모리를 가장 많이 쓰는 컨테이너 이름**을 `~/answer.txt` 에 저장하세요.
2. 그 컨테이너를 **같은 이미지, 같은 이름**으로 다시 만들되 **메모리 상한 256MB** (`256m`) 를 거세요.
3. 다시 만든 컨테이너는 **정상 실행 중**이어야 하고, 다른 컨테이너는 건드리지 마세요.

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `docker stats` | 컨테이너별 CPU·메모리 실시간 (`Ctrl+C` 종료) |
| `docker stats --no-stream` | 한 번만 찍기 |
| `docker inspect -f '{{.Config.Image}}' 이름` | 어떤 이미지로 만들었는지 |
| `docker inspect -f '{{.HostConfig.Memory}}' 이름` | 메모리 상한 (0 = 무제한) |
| `docker run -d --name 이름 --memory 256m 이미지` | 상한을 걸고 실행 |
