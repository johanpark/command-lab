# 팀 공유 폴더 만들기

새 팀원 **kim** 이 들어왔습니다. 웹사이트 소스가 있는 `/srv/website` 폴더를 나(learner)와 kim 이 **함께 수정**할 수 있게 해 주세요. 다른 사람은 들어오면 안 됩니다.

## 먼저 알아 둘 것: 권한은 세 칸
`ls -ld /srv/website` 를 쳐 보면 이렇게 나와요.
```
drwxr-xr-x 4 root root 4096 Nov  3 14:00 /srv/website
```
| 부분 | 뜻 |
|---|---|
| `d` | 폴더라는 표시 |
| `rwx` (2~4번째 글자) | **소유자**가 할 수 있는 것 |
| `r-x` (5~7번째) | **그룹**에 속한 사람들이 할 수 있는 것 |
| `r-x` (8~10번째) | **기타**, 나머지 모두가 할 수 있는 것 |
| 첫 번째 `root` | 이 폴더의 **소유자** |
| 두 번째 `root` | 이 폴더의 **그룹** |

learner 는 소유자도 아니고 root 그룹도 아니라서 **기타** 칸(`r-x`)을 적용받아요. 그래서 읽기만 되고 수정은 안 돼요.

그래서 계획은 이래요. **팀(그룹) `webdev` 를 만들어 두 사람을 넣고 → 폴더의 그룹을 `webdev` 로 바꾸고 → 그룹 칸에 쓰기 권한을 준다.**

## 목표
1. 사용자 **`kim`** 을 만드세요. 홈 폴더(`/home/kim`)가 있어야 하고, 셸은 `/bin/bash`.
2. 그룹 **`webdev`** 를 만들고 **learner 와 kim** 을 넣으세요.
   ⚠️ learner 는 이미 `designers` 그룹에도 속해 있어요. **거기서 빠지면 안 됩니다.**
3. `/srv/website` 의 그룹을 `webdev` 로 바꾸고, 권한을 **소유자와 그룹은 모두 가능(rwx), 다른 사람은 아무것도 못 함**으로.
4. 이 폴더 안에 새로 만드는 파일도 **자동으로 webdev 그룹**이 되도록 설정하세요. (setgid)

모두 관리자 권한이 필요해요. 명령 앞에 `sudo` 를 붙이세요.

## 권한 숫자 읽는 법
`chmod` 에 쓰는 숫자는 **r=4, w=2, x=1 을 더한 값**을 칸마다 하나씩 적은 거예요.

| 숫자 | 더한 것 | 글자 | 뜻 |
|---|---|---|---|
| 7 | 4+2+1 | `rwx` | 읽기·쓰기·들어가기 다 됨 |
| 5 | 4+1 | `r-x` | 읽기·들어가기만 |
| 0 | — | `---` | 아무것도 못 함 |

예: `chmod 755` → 소유자 `rwx`, 그룹 `r-x`, 기타 `r-x` (지금 상태)

네 자리로 쓰면 **맨 앞 숫자는 특수 권한**이에요. `2` 가 **setgid** 로, 폴더에 걸면 그 안에 새로 만든 파일이 **폴더의 그룹을 물려받아요.**
(이게 없으면 kim 이 만든 파일은 `kim` 그룹이 돼서, learner 가 못 고칠 수 있어요.)

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `sudo useradd -m -s /bin/bash 이름` | 사용자 만들기 (`-m` 홈 폴더 생성, `-s` 셸) |
| `sudo groupadd 그룹` | 그룹 만들기 |
| `sudo usermod -aG 그룹 사용자` | 사용자를 그룹에 **추가** (`-a` 가 "덧붙이기") |
| `id 사용자`, `getent group 그룹` | 소속 그룹 확인 |
| `sudo chgrp 그룹 폴더` | 폴더의 그룹 바꾸기 |
| `sudo chmod 숫자 폴더` | 권한 바꾸기 (위의 표를 보고 숫자를 정해 보세요) |
| `ls -ld 폴더` | 폴더 자체의 권한·소유자·그룹 보기 |
