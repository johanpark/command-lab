# 에러 로그 살펴보기

새벽에 서비스 장애 알림이 왔습니다. 로그 파일 `~/logs/app.log` 는 수천 줄이라 `cat` 으로 보기엔 너무 깁니다.

## 목표
1. `app.log` 에서 **`ERROR` 가 들어간 줄이 몇 개인지** 세어서 그 숫자를 `~/answer.txt` 에 저장
2. **마지막 20줄**을 `~/recent.log` 파일로 저장 (팀장님께 보고용)
3. `ERROR` 줄만 모아서 `~/errors.log` 파일로 저장

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `head -n 5 파일` | 앞에서 5줄 |
| `tail -n 5 파일` | 뒤에서 5줄 |
| `grep 단어 파일` | 단어가 들어간 줄만 출력 |
| `wc -l 파일` | 줄 수 세기 |
| `명령 > 파일` | 출력을 화면 대신 파일로 저장 |
| `명령1 \| 명령2` | 명령1의 출력을 명령2의 입력으로 (파이프) |
