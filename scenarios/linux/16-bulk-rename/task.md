# 사진 파일 이름 한꺼번에 바꾸기

여행 사진을 카메라에서 옮겼더니 `~/photos` 에 `IMG_0001.JPG` 같은 파일이 잔뜩 생겼습니다. 앨범 규칙에 맞게 이름을 바꾸려는데, 하나씩 `mv` 하기엔 너무 많아요.

## 목표
`~/photos` 의 **모든 `.JPG` 파일**을 아래 규칙으로 바꾸세요.

```
IMG_0001.JPG       →  2026-trip_IMG_0001.jpg
IMG_0100 (1).JPG   →  2026-trip_IMG_0100 (1).jpg
```

1. 앞에 `2026-trip_` 을 붙이고
2. 확장자는 소문자 `.jpg` 로
3. `notes.txt` 같은 다른 파일은 그대로 두세요.

## 써볼 문법
```bash
for f in *.JPG; do
  echo "$f"                 # 파일마다 한 번씩 실행
done

f="IMG_0001.JPG"
echo "${f%.JPG}"            # 끝의 .JPG 를 떼어냄 → IMG_0001
echo "앞_${f}"              # 문자열 붙이기 → 앞_IMG_0001.JPG
```

> 💡 `mv` 대신 `echo mv ...` 로 먼저 돌려 보면, 실제로 바꾸지 않고 어떤 명령이 실행될지 미리 볼 수 있어요.
