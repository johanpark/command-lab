# 수상한 접속 IP 찾기

웹 서버가 갑자기 느려졌습니다. 누군가 요청을 엄청나게 보내고 있는 것 같아요. 웹 서버 접속 로그 `~/access.log` 를 분석하세요.

```
203.0.113.7 - - [25/Oct/2026:10:00:01 +0900] "GET /index.html HTTP/1.1" 200 512
└ 접속한 IP                                     └ 요청             └ 상태코드
```

## 목표
1. **요청을 가장 많이 보낸 IP** 를 찾아 `~/answer.txt` 에 저장
2. 요청 수 **상위 5개 IP와 횟수**를 `~/top5.txt` 에 저장
   (형식은 `uniq -c` 가 출력하는 그대로: `   1234 203.0.113.7`)

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `awk '{print $1}' 파일` | 각 줄의 첫 번째 칸만 출력 (`cut -d' ' -f1` 도 가능) |
| `sort` | 정렬 |
| `uniq -c` | 연속된 같은 줄을 합치고 개수 붙이기 (**정렬된 입력** 필요) |
| `sort -rn` | 숫자 기준(n) 내림차순(r) 정렬 |
| `head -n 5` | 앞 5줄 |

> 💡 파이프(`|`)로 명령을 한 단계씩 이어 붙이면서, 매 단계 결과를 눈으로 확인해 보세요.
