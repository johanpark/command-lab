# 지웠는데 디스크가 안 비어요

디스크가 꽉 차서 동료가 큰 로그 파일 `/var/log/shop/app.log` 를 `rm` 으로 지웠습니다. 그런데...

> "분명히 지웠는데 `df` 로 보면 공간이 그대로예요!"

리눅스에서는 **어떤 프로세스가 파일을 열어 둔 채로** 지우면, 이름만 사라지고 내용은 그 프로세스가 놓을 때까지 디스크에 남아요.

## 목표
1. 지워진 파일을 **아직 붙잡고 있는 프로세스 이름**을 `~/answer.txt` 에 저장하세요.
2. 그 프로세스는 결제 로그를 쓰는 중요한 서비스라 **종료하면 안 됩니다.** 프로세스를 살려 둔 채로 그 파일의 공간을 **0 에 가깝게 비우세요.**

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `df -h` / `du -sh 폴더` | 디스크 사용량 (둘이 다르면 의심!) |
| `lsof +L1` | **지워졌지만 열려 있는** 파일 목록 |
| `ls -l /proc/PID/fd` | 프로세스가 연 파일들 (`(deleted)` 표시) |
| `: > 파일` 또는 `truncate -s 0 파일` | 파일을 지우지 않고 내용만 비우기 |
