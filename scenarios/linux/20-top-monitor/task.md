# CPU가 튀는 원인 찾기 (top)

모니터링에서 "CPU 사용률이 몇 초마다 확 튄다", "메모리도 꽤 쓰고 있다"는 알림이 왔습니다. 일단 **아무것도 끄지 말고** 상황부터 파악해서 보고해 달라고 합니다.

## 목표
1. **CPU를 가장 많이 쓰는** 프로세스 이름 → `~/cpu.txt`
   (계속 쓰는 게 아니라 **몇 초마다 튀어요.** 화면을 잠시 지켜보세요)
2. **메모리(RES)를 가장 많이 쓰는** 프로세스 이름 → `~/mem.txt`
3. 보고서에 첨부할 **top 화면 한 장**을 `~/top-report.txt` 로 저장하세요. (top 의 배치 모드)
4. 관찰만 합니다. **어떤 프로세스도 종료하지 마세요.**

## top 화면 읽는 법
```
top - 10:00:01 up 1 day,  load average: 0.85, 0.60, 0.40   ← 1분/5분/15분 평균 부하
%Cpu(s): 66.0 us, ...  0.0 id                                ← id(idle)가 낮을수록 바쁨
MiB Mem :   7800 total,  ...
  PID USER   ... RES   %CPU %MEM  COMMAND
   42 learner    1.0g  99.0  5.0  something
```

## 써볼 키와 옵션
| 입력 | 하는 일 |
|---|---|
| `top` | 실시간 모니터 (`q` 종료) |
| `P` / `M` | CPU 순 / 메모리 순 정렬 |
| `1` | CPU 코어별로 보기 |
| `top -b -n 1` | 화면 대신 **텍스트로 한 번** 출력 (배치 모드) |
| `top -o %MEM` | 처음부터 메모리 순으로 |
| `ps aux --sort=-rss \| head` | 메모리 순 (ps 로) |
