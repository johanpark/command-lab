# 해설

```bash
ls -l ~/deploy.sh            # -rw-r--r--  ← x 가 없음
chmod +x ~/deploy.sh         # -rwxr-xr-x
cd ~ && ./deploy.sh

chmod 600 ~/secrets/api.key  # -rw-------
chmod 700 ~/secrets          # drwx------
ls -la ~/secrets
```

## 권한 읽는 법
```
-rwxr-x---
│└┬┘└┬┘└┬┘
│ │  │  └ 그 외(other): 권한 없음
│ │  └─── 그룹(group): 읽기, 실행
│ └────── 소유자(user): 읽기, 쓰기, 실행
└──────── 종류: - 파일, d 디렉터리
```

| 숫자 | 권한 | 자주 쓰는 예 |
|---|---|---|
| 7 | rwx | 내 스크립트/폴더 |
| 6 | rw- | 내 설정 파일 |
| 5 | r-x | 남들이 실행만 |
| 4 | r-- | 남들이 읽기만 |

`755` (스크립트·폴더 공개), `644` (일반 파일), `600` (비밀 파일), `700` (비밀 폴더) 이 네 개만 외워도 대부분 해결됩니다.

## 기억할 것
- **폴더의 x 권한**은 "그 폴더 안으로 들어갈 수 있는가(cd)"를 뜻합니다.
- `./deploy.sh` 의 `./` 는 "현재 폴더의"라는 뜻. 그냥 `deploy.sh` 라고 치면 PATH 에서만 찾기 때문에 실행되지 않아요.
- 실행 권한 없이도 `bash deploy.sh` 로는 실행할 수 있어요. (bash 가 파일을 "읽어서" 실행하기 때문)
- 권한 문제를 `chmod 777` 로 해결하는 건 **절대 금물**. 모두에게 쓰기 권한을 주는 보안 구멍이에요.
