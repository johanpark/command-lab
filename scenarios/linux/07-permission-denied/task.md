# Permission denied 해결하기

배포 스크립트를 실행하려는데 이런 에러가 납니다.

```
$ ./deploy.sh
bash: ./deploy.sh: Permission denied
```

## 목표
1. `~/deploy.sh` 를 **실행할 수 있게** 만들고, 실제로 `./deploy.sh` 로 **실행**하세요. (실행에 성공하면 `~/deploy-result.txt` 가 생깁니다)
2. 보안 점검에서 `~/secrets/api.key` 를 **누구나 읽을 수 있다**는 지적을 받았습니다. **나(소유자)만 읽고 쓸 수 있게** 권한을 바꾸세요. (`-rw-------`)
3. `~/secrets` 폴더도 **나만 들어갈 수 있게** 바꾸세요. (`drwx------`)

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `ls -l` | 권한 확인 (`-rwxr-xr--` 같은 부분) |
| `chmod +x 파일` | 실행 권한 추가 |
| `chmod 600 파일` | 숫자로 권한 지정 (r=4, w=2, x=1) |
| `./파일` | 현재 폴더의 스크립트 실행 |
