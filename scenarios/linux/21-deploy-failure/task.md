# 배포가 실패했어요

쇼핑몰 서버 v2.3.0 을 배포하려고 `~/deploy.sh` 를 실행했더니 실패합니다.

```
$ ./deploy.sh
▶ 이전 버전 중지
▶ 새 버전 시작
▶ 헬스 체크 (http://localhost:9000/health)
❌ 배포 실패: 헬스 체크에 응답하지 않습니다. 로그를 확인하세요 (~/app/logs)
```

서버 프로그램 `~/app/bin/shop-server` 는 고칠 필요 없어요. **설정과 환경 문제**입니다.

## 목표
1. 로그에서 실패 원인을 찾아 고치세요. 하나를 고치면 **다음 문제가 드러날 수도 있어요.**
2. `./deploy.sh` 가 **✅ 배포 성공** 을 출력하고, `curl http://localhost:9000/health` 가 `ok` 를 돌려줘야 합니다.
3. 설정 파일을 아무나 고칠 수 있게(`chmod 777`, `666`) 만들면 안 됩니다.

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `ls -l ~/app/logs` | 어떤 로그가 있고 언제 바뀌었는지 |
| `tail -n 20 파일` | 로그의 **최근** 부분 |
| `tail -f 파일` | 새로 쌓이는 로그 실시간 보기 (`Ctrl+C` 종료) |
| `ls -l`, `cat` | 설정 파일 상태와 내용 |
| `curl -i http://localhost:9000/health` | 직접 헬스 체크 |

> 💡 장애 대응의 기본 순서: **증상 확인 → 최근 로그 → 원인 하나 고치기 → 다시 시도 → 반복**
