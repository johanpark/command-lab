# 두 파일 비교하기

두 가지 비교 업무가 들어왔어요.

**① 설정이 뭐가 바뀌었지?** 어제 설정 `~/config-old.conf` 와 오늘 설정 `~/config-new.conf` 를 비교하면 설정 몇 개가 추가·삭제·변경됐어요.

**② 휴면 계정 정리**: `~/all-users.txt` 는 전체 회원 아이디(정렬 안 됨, **중복 있음**), `~/active-users.txt` 는 최근 90일 안에 로그인한 아이디예요.

## 목표
1. 두 설정 파일에 **모두 있지만 값이 바뀐** 설정의 **이름**을 `~/changed.txt` 에 저장하세요. (예: `timeout`)
2. 전체 회원 중 **최근 로그인하지 않은** 아이디를, **중복 없이 가나다/알파벳 순으로 정렬**해서 한 줄에 하나씩 `~/dormant.txt` 에 저장하세요.

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `diff 파일1 파일2` | 다른 줄 보여주기 (`<` 는 파일1, `>` 는 파일2) |
| `diff -u 파일1 파일2` | `-` / `+` 로 보기 좋게 (git diff 와 같은 형식) |
| `sort -u 파일` | 정렬 + 중복 제거 |
| `comm -23 A B` | **정렬된** A, B 에서 A 에만 있는 줄 |
| `wc -l` | 줄 수 |
