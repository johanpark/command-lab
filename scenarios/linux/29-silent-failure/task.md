# 실패했는데 "배포 성공"이래요

`~/deploy.sh 2.5.0` 을 실행하면 매번 `✅ 배포 성공!` 이 나와요. 그런데 사이트에는 **여전히 옛날 버전**이 떠 있습니다.

```
$ cat ~/www/version.txt
2.4.3
```

스크립트가 중간에 실패해 놓고도 끝까지 달려가서 "성공"을 외치고 있는 것 같아요.

## 목표
1. 스크립트를 고쳐서, **어느 단계든 실패하면 즉시 멈추고 0 이 아닌 종료 코드**로 끝나게 하세요. (실패했을 때 "배포 성공" 이 출력되면 안 돼요)
2. 실패의 **진짜 원인**을 찾아 고치고 `~/deploy.sh 2.5.0` 으로 배포를 완료하세요. → `~/www/version.txt` 가 `2.5.0`

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `bash -x ~/deploy.sh 2.5.0` | 한 줄씩 **무엇이 실행되는지** 보여주며 실행 |
| `echo $?` | 방금 명령의 종료 코드 (0 = 성공) |
| `set -e` | 스크립트에서 명령이 실패하면 즉시 종료 |
| `set -u` | 정의 안 된 변수를 쓰면 에러 |
| `set -o pipefail` | 파이프 중간 명령의 실패도 실패로 |
| `ls -l ~/build` | 빌드 결과물 확인 |
