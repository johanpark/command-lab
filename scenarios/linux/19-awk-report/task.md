# 매출 리포트 만들기

편의점 본사에서 이번 달 판매 기록 `~/sales.csv` 를 보냈습니다. 엑셀 없이 터미널에서 리포트를 만들어 봅시다.

```
date,category,item,qty,unit_price
2026-10-01,음료,콜라,3,1800
```

## 목표
1. **카테고리별 매출 합계**(qty × unit_price 의 합)를 구해서 **매출이 큰 순서**로 `~/report.txt` 에 저장하세요.
   한 줄에 `카테고리 매출` 형식 (공백 하나로 구분):
   ```
   라면 1234500
   음료 987600
   ...
   ```
2. **판매 수량(qty) 합계가 가장 많은 상품 이름**을 `~/answer.txt` 에 저장하세요.

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `head sales.csv`, `wc -l sales.csv` | 생김새와 크기 확인 |
| `awk -F, '{print $2}'` | 쉼표로 나눠 2번째 칸 |
| `awk -F, 'NR > 1 {...}'` | 첫 줄(머리글) 건너뛰기 |
| `awk '{s[$1] += $2} END {for (k in s) print k, s[k]}'` | 키별 합계 (연관 배열) |
| `sort -k2 -nr` | 2번째 칸 기준 숫자 내림차순 |
