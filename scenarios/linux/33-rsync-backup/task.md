# rsync 로 백업 동기화

사진 폴더 `~/photos` 를 백업 디스크 `/mnt/backup/photos` 에 백업하고 있어요. 지난 백업 이후 사진이 추가되고, 수정되고, 몇 장은 지웠습니다.

## 목표
`/mnt/backup/photos` 를 `~/photos` 와 **완전히 똑같이** 만드세요.
1. 새로 생긴 사진·폴더는 백업에 추가
2. 바뀐 사진은 백업도 새 내용으로
3. 원본에서 지운 사진은 백업에서도 삭제
4. 파일 **수정 시각과 권한도** 원본과 같게
5. `/mnt/backup/photos` 안에 `photos` 폴더가 **또 생기면 안 돼요** (`photos/photos`)

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `rsync -a 원본/ 대상/` | 원본 폴더의 **내용**을 대상에 맞춤 (`-a` = 권한·시각 등 보존) |
| `rsync -a 원본 대상/` | 원본 **폴더 자체**를 대상 안에 복사 (끝 `/` 없음!) |
| `--delete` | 원본에 없는 파일을 대상에서 삭제 |
| `-n` (`--dry-run`) | **실제로 하지 않고** 무엇을 할지만 보여주기 |
| `-v` | 처리하는 파일 목록 출력 |
| `diff -r 폴더1 폴더2` | 결과 확인 |
