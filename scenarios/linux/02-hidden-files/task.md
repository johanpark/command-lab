# 숨겨진 설정 파일

웹 서비스가 데이터베이스에 연결하지 못하고 있습니다. 동료가 이렇게 말합니다.

> "`~/webapp` 폴더에 설정 파일이 있을 텐데... `ls` 해도 안 보인다고요? 아, 그거 **숨김 파일**이에요."

## 목표
1. `~/webapp` 폴더에 숨어 있는 설정 파일을 찾아서 **DB_PORT** 값을 확인하세요.
2. 그 포트 번호를 `~/answer.txt` 에 저장하세요.

```bash
echo 포트번호 > ~/answer.txt
```

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `ls -a` | 숨김 파일(이름이 `.` 으로 시작)까지 모두 보기 |
| `ls -l` | 권한·소유자·크기·수정 시각까지 자세히 보기 |
| `ls -la` | 둘을 합친 것 |
| `cat` / `less` | 파일 읽기 (`less` 는 `q` 로 종료) |
