# 터미널을 닫아도 작업이 계속 돌게

`~/backup/long-backup.sh` 는 **30분쯤 걸리는** 백업 스크립트예요. 어제 SSH 로 접속해서 돌려 놓고 퇴근했는데, 노트북을 닫는 순간 접속이 끊기면서 **백업도 같이 죽어 버렸어요.**

터미널(SSH 세션)이 끊기면 그 터미널에서 실행한 프로그램들에 **SIGHUP**(끊김) 신호가 가고, 대부분의 프로그램은 이 신호를 받으면 종료돼요.

## 목표
1. `~/backup/long-backup.sh` 를 **터미널이 닫혀도 계속 돌도록** 백그라운드로 실행하세요.
2. 출력(진행 상황)과 에러는 **`~/backup/backup.log`** 에 남기세요.
3. 실행해 놓고도 **이 터미널에서 계속 다른 명령을 칠 수 있어야** 해요.

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `명령 &` | 백그라운드로 실행 (터미널이 닫히면 같이 죽음) |
| `nohup 명령 &` | SIGHUP 을 **무시**하고 실행 |
| `명령 > 로그 2>&1` | 출력과 에러를 파일로 |
| `jobs` / `fg` / `bg` | 이 터미널의 백그라운드 작업 / 앞으로 / 뒤로 |
| `disown` | 작업을 이 셸의 관리에서 떼어 내기 |
| `ps -ef \| grep long-backup` | 실행 중인지 확인 |
| `tail -f 로그` | 로그 실시간으로 보기 (`Ctrl+C` 로 그만 보기) |
