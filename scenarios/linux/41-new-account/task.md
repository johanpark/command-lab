# 신입 서버 계정 만들기

인프라팀에 온 요청서 `~/onboarding/request.txt` 를 처리해야 해요. 신입 개발자의 서버 계정을 만들고, 기존 팀원 한 명에게 배포 권한(그룹)을 추가해 달래요.

## 목표
1. 요청서의 **신입 계정**을 만드세요.
   - 홈 폴더 `/home/<계정>` 이 있어야 하고, 로그인 셸은 **`/bin/bash`**
   - 보조 그룹: **`developers`** (요청서에 없는 그룹은 넣지 마세요)
2. 신입이 SSH 키로 접속할 수 있게 **`~/onboarding/` 의 공개키**를 그 계정의 `~/.ssh/authorized_keys` 에 넣으세요.
   - `.ssh` 폴더는 **700**, `authorized_keys` 는 **600**, 둘 다 **그 계정 소유**여야 해요. (아니면 sshd 가 키를 무시해요)
3. 기존 팀원 **`jun`** 을 **`deploy`** 그룹에 추가하세요. jun 이 원래 속한 그룹(`developers`, `audit`)은 **그대로 유지**돼야 하고, 그 밖의 그룹은 더하지 마세요.

관리 명령은 `sudo` 를 붙여서 실행하세요.

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `id 계정` | 계정의 uid, 그룹 |
| `getent passwd 계정` | 홈 폴더, 셸 확인 |
| `sudo useradd -m -s /bin/bash -G 그룹 계정` | 계정 만들기 (`-m` 홈 폴더 생성) |
| `sudo usermod -aG 그룹 계정` | 그룹 **추가** (`-a` 가 없으면 **교체**!) |
| `sudo install -d -m 700 -o 계정 -g 계정 폴더` | 권한·소유자까지 정해서 폴더 만들기 |
| `sudo chown -R 계정:계정 경로` / `sudo chmod 600 파일` | 소유자 / 권한 바꾸기 |
| `sudo ls -la /home/계정/.ssh` | 결과 확인 |
