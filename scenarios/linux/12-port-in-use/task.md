# 포트가 이미 사용 중입니다

새 버전의 앱을 배포하려는데 실행이 안 됩니다.

```
$ ~/myapp/start.sh
에러: 8080 포트가 이미 사용 중입니다.
```

예전 버전의 무언가가 아직 8080 포트를 붙잡고 있는 것 같아요.

## 목표
1. **8080 포트를 쓰고 있는 프로세스의 이름**을 `~/answer.txt` 에 저장하세요.
2. 그 프로세스를 **종료**하세요.
3. `~/myapp/start.sh` 를 실행해서 **우리 앱(`myapp`)이 8080 포트에서 동작**하게 하세요.
4. 같은 서버의 `metrics` (9100 포트)는 **건드리면 안 됩니다.**

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `ss -ltn` | 열려 있는(Listen) TCP 포트 |
| `sudo ss -ltnp` | 포트와 그 포트를 쓰는 **프로세스 이름·PID** |
| `sudo lsof +c 0 -i :8080` | 8080 포트를 쓰는 프로세스 (`+c 0`: 이름을 자르지 않음) |
| `ps -p PID -o pid,user,comm,args` | PID 로 프로세스 자세히 보기 |
| `sudo kill PID` | 종료 |

> 💡 `ss` 옵션 외우는 법: **l**isten, **t**cp, **n**umeric(포트를 숫자로), **p**rocess
>
> ⚠️ 다른 사용자(root 등)의 프로세스는 `sudo` 없이 보면 **프로세스 칸이 비어 있어요.** 이름이 안 보이면 `sudo` 를 붙이세요.
