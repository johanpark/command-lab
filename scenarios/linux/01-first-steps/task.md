# 처음 접속한 서버에서 메모 찾기

오늘부터 서버 관리를 맡게 됐습니다. 전임자가 "**projects 폴더 안 어딘가에 오늘의 암호를 적은 메모를 남겨뒀다**"고 합니다.

## 목표
1. 홈 디렉터리의 `projects` 폴더를 돌아다니며 **메모 파일**을 찾으세요.
2. 메모에 적힌 **암호**를 아래처럼 `~/answer.txt` 에 저장하세요.

```bash
echo 여기에암호 > ~/answer.txt
```

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `pwd` | 지금 내가 있는 위치(디렉터리) 출력 |
| `ls` | 현재 위치의 파일/폴더 목록 |
| `cd 폴더명` | 폴더로 이동 (`cd ..` 은 한 단계 위로, `cd ~` 은 홈으로) |
| `cat 파일명` | 파일 내용 출력 |

> 다 했으면 `check` 로 채점해 보세요. 막히면 `hint`.
