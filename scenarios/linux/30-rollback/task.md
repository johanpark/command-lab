# 새 버전이 망가졌어요, 롤백!

방금 **2.4.0** 을 배포했는데 헬스 체크가 실패해요. 원인 분석은 나중에 하고, **일단 직전 버전으로 되돌려야** 합니다.

이 서버는 버전별 폴더와 `current` 링크로 배포해요.
```
~/app/
├── releases/
│   ├── 2.3.0/
│   ├── 2.3.1/      ← 직전 버전
│   └── 2.4.0/      ← 방금 배포 (망가짐)
├── current -> releases/2.4.0     ← 서버는 이 경로를 서비스
└── restart.sh                    ← 서버 재시작
```

## 목표
1. `current` 가 **`releases/2.3.1`** 을 가리키게 바꾸고 `~/app/restart.sh` 로 재시작하세요.
2. `curl http://localhost:8080/health` 가 `ok` 를, `curl http://localhost:8080/version.txt` 가 `2.3.1` 을 돌려줘야 해요.
3. 원인 분석을 위해 **2.4.0 폴더는 그대로** 두세요. (지우거나 안에 뭘 만들면 안 돼요)
4. 2.3.1 에는 있는데 **2.4.0 에서 빠진 파일의 이름**을 `~/answer.txt` 에 저장하세요.

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `ls -l ~/app` | `current -> releases/2.4.0` 처럼 링크 대상 표시 |
| `readlink ~/app/current` | 링크가 가리키는 경로 |
| `ln -sfn 대상 링크이름` | 링크를 **새 대상으로 바꾸기** (`-n` 이 중요!) |
| `diff -r 폴더1 폴더2` | 두 폴더를 통째로 비교 |
