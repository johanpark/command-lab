# 윈도우에서 고친 배포 스크립트

동료가 Windows 에서 배포 스크립트를 조금 고쳐서 서버에 올렸어요. 그런데 실행하자마자 이상한 에러가 납니다.

```
$ cd ~/deploy && ./deploy.sh
/usr/bin/env: 'bash\r': No such file or directory
```

분명 `bash` 는 있는데... 저 `\r` 은 뭘까요?

## 목표
1. `~/deploy` 폴더의 **모든 `.sh` 파일**에서 문제를 고치세요. (스크립트가 하나가 아니에요)
2. `./deploy.sh` 를 실행해서 **배포를 완료**하세요. 성공하면 `~/site/version.txt` 가 생깁니다.
3. 스크립트들은 계속 **실행 권한**이 있어야 해요.

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `file 파일` | 파일 종류 (줄바꿈 형식까지 알려줌) |
| `cat -A 파일` | 보이지 않는 문자까지 표시 (`^M` = `\r`, `$` = 줄 끝) |
| `grep -l $'\r' *.sh` | `\r` 이 들어 있는 파일 찾기 |
| `sed -i 's/\r$//' 파일` | 줄 끝의 `\r` 지우기 |
