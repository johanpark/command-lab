`vim ~/app.conf` 로 열고, 화면 아래에 `-- INSERT --` 가 **안** 보이면 명령 모드예요. 이 상태에서 `/8080` + Enter 를 누르면 8080 이 있는 곳으로 커서가 가요.
---
숫자를 바꾸려면: 커서를 `8` 위에 두고 `x` 를 네 번 눌러 지우고, `i` 를 눌러 `9090` 을 입력한 다음 `Esc`. (또는 `cw` = 단어를 지우고 바로 입력 모드)
---
`debug = true` 줄로 커서를 옮긴 뒤 `dd`. 그다음 `G` 로 맨 끝 줄로 가서 `o` → `timezone = Asia/Seoul` 입력 → `Esc`
---
`:wq` 입력 후 Enter. 망쳤다면 `:q!` 로 저장 없이 나와서 다시 시작하세요. `cat ~/app.conf` 로 결과를 확인!
