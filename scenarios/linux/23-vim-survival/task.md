# vim 만 있는 서버

이 서버에는 nano 가 **없습니다.** 많은 서버가 이래요. 남은 건 `vim` 뿐! 처음 vim 을 열면 글자도 안 써지고 나가는 법도 몰라서 당황하기 쉬워요. 이번에 확실히 익혀 둡시다.

## 목표
`vim ~/app.conf` 로 파일을 열어서:
1. `port = 8080` 을 **`port = 9090`** 으로 바꾸세요.
2. `debug = true` **줄을 통째로 지우세요.**
3. 파일 **맨 끝**에 `timezone = Asia/Seoul` 줄을 추가하세요.
4. **저장하고 나오세요.**

## vim 생존 키
vim 에는 **모드**가 있어요. 처음엔 "명령 모드"라서 키를 누르면 글자가 아니라 명령이 실행돼요.

| 키 | 하는 일 |
|---|---|
| `i` | 입력 모드로 (커서 앞에 글자 쓰기) |
| `Esc` | 명령 모드로 돌아오기 (**헷갈리면 일단 Esc**) |
| `h` `j` `k` `l` 또는 화살표 | 커서 이동 |
| `x` | 커서 위 글자 지우기 |
| `dd` | 현재 줄 지우기 |
| `o` | 아래에 새 줄 만들고 입력 모드 |
| `G` | 파일 맨 끝으로 |
| `u` | 되돌리기 |
| `:wq` + Enter | 저장하고 나가기 |
| `:q!` + Enter | **저장하지 않고** 나가기 (망쳤을 때) |
