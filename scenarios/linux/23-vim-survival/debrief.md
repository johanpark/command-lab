# 해설

```
vim ~/app.conf
/8080          ← 검색해서 이동
cw9090<Esc>    ← 단어 바꾸기 (change word)
j dd           ← 아래 줄(debug)로 가서 줄 삭제
G o timezone = Asia/Seoul <Esc>
:wq
```

## 모드 한 장 정리
```
          i, a, o
 명령 모드 ────────▶ 입력 모드
    ▲  │              │
    │  │ :            │ Esc
    │  ▼              │
 명령줄 모드 ◀────────┘
 (:wq, :q!, /검색)
```

## 이것만 외워도 살아남아요
| 상황 | 키 |
|---|---|
| 뭐가 뭔지 모르겠다 | `Esc` 두세 번 |
| 저장하고 나가기 | `:wq` (또는 `ZZ`) |
| 저장 없이 나가기 | `:q!` |
| 되돌리기 / 다시 하기 | `u` / `Ctrl+r` |
| 줄 삭제 / 줄 복사 / 붙여넣기 | `dd` / `yy` / `p` |
| 찾기 / 다음 | `/단어` / `n` |
| 모두 바꾸기 | `:%s/옛/새/g` |
| 줄 번호 보기 | `:set number` |

## 다음에 vim 이 갑자기 열리면
`git commit` 에 `-m` 을 빼먹거나, `crontab -e`, `visudo` 처럼 **기본 편집기**가 vim 인 명령이 많아요. 당황하지 말고 `Esc` → `:q!` 로 나오거나, `:wq` 로 저장하세요. 기본 편집기를 바꾸려면 `export EDITOR=nano`.
