# CPU를 잡아먹는 프로세스

서버 CPU 사용률이 100%에 붙어 있다는 알림이 왔습니다. 이 서버에서는 몇 개의 프로그램이 돌고 있어요.

- `web-server` — 서비스 중인 웹 서버. **절대 끄면 안 됩니다.**
- `log-shipper` — 로그 전송기. **끄면 안 됩니다.**
- 그리고... 정체불명의 무언가

## 목표
1. **CPU를 가장 많이 쓰는 프로세스**를 찾아 이름을 `~/answer.txt` 에 저장하세요.
2. 그 프로세스를 **종료**하세요.
3. `web-server` 와 `log-shipper` 는 **계속 실행 중**이어야 합니다.

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `ps aux` | 실행 중인 모든 프로세스 (PID, CPU%, 메모리%, 명령) |
| `ps aux --sort=-%cpu \| head` | CPU 많이 쓰는 순으로 |
| `top` | 실시간 모니터링 (`q` 로 종료, `P` 는 CPU순 정렬) |
| `pgrep -a 이름` | 이름으로 PID 찾기 |
| `kill PID` | 프로세스에 종료 요청 |
