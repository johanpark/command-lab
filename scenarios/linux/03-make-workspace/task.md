# 블로그 작업 폴더 만들기

블로그를 시작하려고 합니다. 홈 디렉터리에 흩어져 있는 파일을 정리해 봅시다.

## 목표
아래 구조를 만드세요.

```
~/blog/
├── README.md              ← ~/templates/README.md 를 "복사" (원본은 그대로 둘 것)
├── posts/
│   └── 2026-hello.md      ← ~/draft.md 를 "이동"하면서 이름 변경 (원래 위치엔 없어야 함)
├── images/                ← 빈 폴더
└── drafts/
    └── ideas.md           ← 새로 만든 빈 파일
```

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `mkdir 폴더` | 폴더 만들기 (`mkdir -p a/b/c` 는 중간 폴더까지 한 번에) |
| `touch 파일` | 빈 파일 만들기 |
| `cp 원본 대상` | 복사 |
| `mv 원본 대상` | 이동 (같은 폴더 안에서 쓰면 이름 변경) |
| `tree` | 폴더 구조를 나무 모양으로 보기 |
