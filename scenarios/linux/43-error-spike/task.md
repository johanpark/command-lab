# 몇 시 몇 분에 장애가 났지? (시간대별 집계)

오늘 오후에 결제가 잠깐 안 됐다는 고객 문의가 여러 건 들어왔어요. 장애 보고서를 쓰려면 **정확한 시각**이 필요해요. 웹 서버 로그 `~/logs/access.log` 에 하루치 요청이 있어요.

```
2026-10-28T14:03:12+09:00 GET /api/orders 200 123ms
2026-10-28T14:03:13+09:00 POST /api/pay 502 3001ms
```
(시각 · 메서드 · 주소 · **상태 코드** · 응답 시간)

서버 장애는 **5xx**(500, 502, 503 …) 상태 코드로 나타나요. 404 같은 4xx 는 손님 쪽 실수(없는 주소)라서 장애가 아니에요.

## 목표
1. **5xx 응답이 가장 많았던 1분**을 `HH:MM` 형식(예: `14:03`)으로 `~/answer.txt` 에 저장하세요.
2. **시간(HH)별 5xx 개수**를 `~/by_hour.txt` 에 저장하세요. 한 줄에 `HH 개수`, **시간 순서대로**, 5xx 가 있었던 시간만.
   ```
   00 3
   01 1
   ...
   ```

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `awk '$4 >= 500' 파일` | 4번째 칸(상태 코드)이 500 이상인 줄 |
| `cut -c12-16` | 각 줄의 12~16번째 글자 (`14:03`) |
| `sort \| uniq -c` | 같은 값끼리 세기 (`개수 값`) |
| `sort -rn \| head` | 많은 순으로 |
| `awk '{print $2, $1}'` | 칸 순서 바꾸기 |
