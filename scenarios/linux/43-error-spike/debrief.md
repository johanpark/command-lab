# 해설

```bash
L=~/logs/access.log
# 1. 5xx 가 가장 많았던 1분
awk '$4 >= 500' $L | cut -c12-16 | sort | uniq -c | sort -rn | head -1 | awk '{print $2}' > ~/answer.txt
# 2. 시간별 5xx
awk '$4 >= 500' $L | cut -c12-13 | sort | uniq -c | awk '{print $2, $1}' > ~/by_hour.txt
```

awk 하나로 하면:
```bash
awk '$4 >= 500 { n[substr($1, 12, 2)]++ } END { for (h in n) print h, n[h] }' $L | sort
```

## 시간대별 집계 공식
```
필터(무엇을 셀지) → 자르기(어떤 단위로) → sort → uniq -c → 정렬
```
- 단위만 바꾸면 돼요: 10분 단위는 `cut -c12-15` (`14:0`), 하루 단위는 `cut -c1-10`.
- `uniq` 는 **붙어 있는 같은 줄**만 합쳐요. 그래서 앞에 `sort` 가 꼭 필요해요. (로그는 이미 시간순이라 이번엔 없어도 되지만 습관으로!)

## 에러라고 다 장애는 아니에요
| 코드 | 뜻 | 누구 문제 |
|---|---|---|
| 2xx | 성공 | |
| 3xx | 다른 곳으로 (리다이렉트) | |
| 4xx | 요청이 잘못됨 (404 없음, 401 인증 필요, 429 너무 많음) | 대개 손님/봇 |
| 5xx | 서버가 처리 못 함 (500 오류, 502/503/504 뒤쪽 서버 문제) | **우리** |

봇이 없는 주소를 마구 두드리면 404 가 폭주하지만 서비스는 멀쩡해요. 알림을 걸 때도 **5xx 비율**을 기준으로 거는 게 보통이에요.
