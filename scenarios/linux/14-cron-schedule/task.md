# 정해진 시간에 자동으로 실행하기

매번 손으로 돌리던 스크립트 세 개를 자동으로 실행되게 하려고 합니다. 리눅스에서는 **cron** 이 이 일을 해요.

## 목표
내 계정(learner)의 crontab 에 아래 세 작업을 등록하세요.

| 스크립트 | 언제 |
|---|---|
| `~/scripts/backup.sh` | **매일 새벽 3시 30분** |
| `~/scripts/report.sh` | **평일(월~금) 오전 9시 정각** |
| `~/scripts/health.sh` | **5분마다** |

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `crontab -l` | 내 crontab 보기 |
| `crontab -e` | 편집기로 crontab 수정 (nano: `Ctrl+O` 저장, `Ctrl+X` 종료) |
| `crontab 파일` | 파일 내용으로 crontab 통째로 교체 |

## cron 표현식
```
┌───────── 분 (0-59)
│ ┌─────── 시 (0-23)
│ │ ┌───── 일 (1-31)
│ │ │ ┌─── 월 (1-12)
│ │ │ │ ┌─ 요일 (0-7, 0과 7은 일요일, 1은 월요일)
│ │ │ │ │
* * * * *  실행할 명령
```
`*` 는 "매번", `*/10` 은 "10마다", `1-5` 는 "1부터 5까지", `1,15` 는 "1과 15" 예요.
