# 해설

`crontab -e` 로 연 편집기에 다음 세 줄을 추가합니다.

```
30 3 * * *   /home/learner/scripts/backup.sh
0 9 * * 1-5  /home/learner/scripts/report.sh
*/5 * * * *  /home/learner/scripts/health.sh >> /home/learner/scripts/health.log 2>&1
```

## 자주 하는 실수
- `* 3 * * *` 는 "3시 정각"이 아니라 **3시대 매 분(60번)** 입니다. 분 칸을 꼭 채우세요.
- cron 은 로그인 셸이 아니라서 **PATH 가 짧고 `.bashrc` 를 읽지 않아요.** 스크립트와 명령은 전체 경로로 쓰는 습관을 들이세요.
- 출력이 어디로도 안 가서 실패해도 모를 수 있어요. `>> 로그파일 2>&1` 로 남겨 두세요.
- `crontab -r` 은 **확인 없이 crontab 전체를 지웁니다.** `-e` 와 자판 위치가 붙어 있으니 조심!

## 자주 쓰는 표현식
| 표현식 | 뜻 |
|---|---|
| `0 * * * *` | 매시 정각 |
| `*/15 * * * *` | 15분마다 |
| `0 0 * * 0` | 매주 일요일 자정 |
| `0 0 1 * *` | 매월 1일 자정 |
| `@reboot` | 부팅할 때 한 번 |
