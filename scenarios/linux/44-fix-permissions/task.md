# chmod -R 777 을 되돌려라

어젯밤 업로드가 안 된다는 장애에, 누군가 급하게 이렇게 쳤대요.
```
sudo chmod -R 777 /srv/www
```
업로드는 됐지만 이제 **서버의 아무나 웹사이트 파일을 고치고 비밀번호를 읽을 수 있는** 상태예요. 보안 점검에 걸렸어요.

## 목표 (`/srv/www` 아래 전부)
| 대상 | 권한 | 뜻 |
|---|---|---|
| 모든 **폴더** | `755` | 나는 전부, 남은 들어가서 보기만 |
| 모든 **일반 파일** | `644` | 나는 읽고 쓰기, 남은 읽기만 |
| `bin/` 의 **`.sh` 스크립트** | `755` | 실행할 수 있어야 함 |
| `config/secret.php` | `640` | 그룹(`www-data`, 웹 서버)만 읽기, 남은 아무것도 못 함 |

파일 내용과 소유자는 바꾸지 마세요. 이 폴더는 내 계정 소유라 `sudo` 없이 바꿀 수 있어요.

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `ls -la /srv/www` / `stat -c '%a %n' 파일` | 권한 확인 (`%a` 는 숫자로) |
| `find /srv/www -type d` | 폴더만 |
| `find /srv/www -type f` | 파일만 |
| `find ... -exec chmod 644 {} +` | 찾은 것들에 한꺼번에 chmod |
| `chmod 755 파일...` | 권한 바꾸기 |
