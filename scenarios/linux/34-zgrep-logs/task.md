# 압축된 옛 로그에서 찾기

고객센터에서 "며칠 전 주문 **`ORDER_ID`** 결제가 실패했다"는 문의가 왔어요. 로그는 매일 순환되고, 오래된 건 압축돼 있습니다.

```
~/logs/
├── app.log          ← 오늘
├── app.log.1        ← 어제
├── app.log.2.gz     ← 그제 (압축)
├── app.log.3.gz
└── ...
```

(주문 번호는 `~/request.txt` 에 있어요)

## 목표
1. 그 주문의 **에러(`ERROR`) 줄이 들어 있는 로그 파일 이름**(예: `app.log.3.gz`)을 `~/answer.txt` 에 저장하세요.
2. 원인을 알려면 에러 **바로 앞의 2줄**이 필요해요. 그 2줄과 에러 줄, 총 3줄을 `~/incident.txt` 에 저장하세요.

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `zcat 파일.gz` | 압축을 풀어서 출력 (파일은 그대로) |
| `zgrep 패턴 파일들` | 압축 파일·일반 파일 모두에서 grep |
| `grep -l` | 일치하는 **파일 이름만** |
| `grep -B 2` / `-A 2` / `-C 2` | 앞 2줄 / 뒤 2줄 / 앞뒤 2줄 같이 출력 |
| `grep -h` | 여러 파일을 찾을 때 파일 이름 접두어 빼기 |
