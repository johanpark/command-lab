# 설정 파일 일괄 수정하기

DB 서버를 이전했습니다. `~/services` 아래 여러 서비스의 설정 파일(`config.ini`)에 옛 주소가 적혀 있어요. 파일을 하나씩 열어서 고치기엔 너무 많습니다.

## 목표
1. 모든 설정 파일에서 `old-db.internal` 을 **`new-db.internal`** 로 바꾸세요. (한 파일에 여러 번 나올 수도 있어요)
2. 운영 환경이니 `debug = true` 를 모두 **`debug = false`** 로 바꾸세요.
3. 그 밖의 내용은 **한 글자도 바뀌면 안 됩니다.**

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `grep -rn 단어 폴더` | 폴더 안 모든 파일에서 찾기 (줄 번호 포함) |
| `grep -rl 단어 폴더` | 단어가 들어 있는 **파일 이름만** |
| `sed 's/옛/새/g' 파일` | 바꾼 결과를 **화면에만** 출력 (파일은 그대로) |
| `sed -i 's/옛/새/g' 파일` | 파일을 **직접** 수정 |

> 💡 `sed -i` 는 되돌리기 어려워요. 항상 `-i` 없이 먼저 실행해서 결과를 눈으로 확인하세요.
