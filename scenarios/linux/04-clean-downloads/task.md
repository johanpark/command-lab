# 다운로드 폴더 대청소

`~/Downloads` 폴더가 파일 수십 개로 엉망입니다. 하나씩 옮기기엔 너무 많아요. **와일드카드**를 써서 한 번에 정리하세요.

## 목표
1. 사진(`.jpg`, `.png` — 대문자 확장자도 포함)은 전부 `~/Downloads/images/` 로 이동
2. 문서(`.pdf`)는 전부 `~/Downloads/docs/` 로 이동
3. 임시 파일(`.tmp`)은 전부 삭제
4. 압축 파일(`.zip`)은 그대로 `~/Downloads` 에 둘 것

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `ls *.jpg` | `.jpg` 로 끝나는 파일만 보기 (`*` 는 "아무 글자나 몇 개든") |
| `mv *.pdf docs/` | 여러 파일을 한 번에 이동 |
| `rm *.tmp` | 여러 파일을 한 번에 삭제 (⚠️ 휴지통 없음!) |
| `ls \| wc -l` | 파일 개수 세기 |

> ⚠️ `rm` 은 되돌릴 수 없어요. 지우기 전에 `ls *.tmp` 로 **무엇이 지워질지 먼저 확인**하는 습관을 들이세요.
