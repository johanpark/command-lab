# 해설

```bash
cd ~/Downloads
mkdir images docs
ls *.jpg *.JPG *.png        # 옮길 대상 미리 확인
mv *.jpg *.JPG *.png images/
mv *.pdf docs/
ls *.tmp                    # 지울 대상 미리 확인
rm *.tmp
ls                          # zip 두 개 + 폴더 두 개만 남았는지
```

## 함정 포인트
- **대소문자**: 리눅스는 대소문자를 구분합니다. `*.jpg` 는 `DSC_0099.JPG` 를 잡지 못해요.
- **공백이 든 이름**: `여행 사진 1.jpg` 를 직접 쓸 땐 `"여행 사진 1.jpg"` 처럼 따옴표가 필요하지만, 와일드카드는 알아서 처리해 줍니다.
- `~lock.tmp` 처럼 특이한 이름도 `*.tmp` 에 걸립니다.

## 와일드카드 정리
| 패턴 | 뜻 | 예 |
|---|---|---|
| `*` | 아무 글자 0개 이상 | `*.log` |
| `?` | 아무 글자 정확히 1개 | `IMG_20??.jpg` |
| `[abc]` | 괄호 안 글자 중 하나 | `*.[jJ][pP][gG]` |
| `{a,b}` | a 또는 b로 펼치기 | `*.{jpg,png}` |
