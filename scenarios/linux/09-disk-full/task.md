# 디스크가 꽉 찼어요

`~/app` 아래에서 서비스가 돌고 있는데 "디스크 공간 부족" 경고가 떴습니다. 어딘가에 **비정상적으로 큰 파일**이 있는 것 같아요.

## 목표
1. `~/app` 아래에서 **가장 큰 파일**을 찾아 그 **경로**를 `~/answer.txt` 에 저장하세요.
   (예: `/home/learner/app/어딘가/파일이름` 또는 `~/app/...` 둘 다 OK)
2. 그 파일을 **삭제**하세요.
3. **다른 파일은 지우면 안 됩니다.** (설정, 업로드, 최근 로그는 서비스에 필요해요)

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `du -sh 폴더/*` | 폴더 안 항목별 용량 (s: 합계, h: 사람이 읽기 좋은 단위) |
| `du -ah 폴더 \| sort -h \| tail` | 모든 파일 용량을 크기순으로 |
| `find 폴더 -type f -size +10M` | 10MB 넘는 파일 찾기 |
| `ls -lhS` | 큰 파일 순으로 목록 |
| `df -h` | 디스크 전체 사용량 |
