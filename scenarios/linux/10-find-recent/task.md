# 어제 누가 설정을 바꿨지?

어제부터 서비스가 이상하게 동작합니다. 누군가 설정을 건드린 것 같은데, `~/app-config` 아래에는 폴더와 파일이 수십 개라 하나씩 열어볼 수가 없어요.

## 목표
1. `~/app-config` 아래(하위 폴더 포함)에서 **최근 1일 이내에 수정된 `.conf` 파일** 목록을 `~/changed.txt` 에 저장하세요. (한 줄에 경로 하나, 순서는 상관없음)
2. 정리하는 김에, `~/app-config` 아래의 **크기가 0인 빈 파일**을 모두 삭제하세요. 내용이 있는 파일과 폴더는 지우면 안 됩니다.

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `find 폴더 -name '*.conf'` | 이름 패턴으로 찾기 (따옴표 필수!) |
| `find 폴더 -mtime -1` | 최근 1일(24시간) 이내 수정된 것 |
| `find 폴더 -type f` | 파일만 (`-type d` 는 폴더만) |
| `find 폴더 -empty` | 비어 있는 파일/폴더 |
| `find ... -delete` | 찾은 것을 삭제 (⚠️ 먼저 `-delete` 없이 확인!) |
| `ls -l --time-style=long-iso` | 수정 시각을 자세히 |

> 💡 조건을 여러 개 쓰면 **모두 만족**하는 것만 찾아요: `find . -type f -name '*.conf' -mtime -1`
