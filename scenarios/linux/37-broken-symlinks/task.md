# 깨진 심볼릭 링크 정리하기

웹 서비스 폴더 `~/site` 를 새 서버로 옮겼어요. 그런데 예전 서버의 경로를 가리키던 **심볼릭 링크** 일부가 이제 아무것도 가리키지 않아요. 이런 링크를 "깨진(dangling) 링크"라고 해요.

```
$ cat ~/site/legacy/index.html
cat: /home/learner/site/legacy/index.html: No such file or directory
```

## 목표
1. `~/site` 아래(숨김 파일, 하위 폴더 포함) **깨진 심볼릭 링크의 개수**를 `~/answer.txt` 에 저장하세요.
2. 그중 `~/site/releases/v3/uploads` 는 지우지 말고, 새 저장소 **`/srv/uploads`** 를 가리키도록 **고치세요.**
3. 나머지 깨진 링크는 **지우세요.**
4. 정상 링크와 진짜 파일은 그대로 둬야 해요.

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `ls -la` | 링크는 `이름 -> 대상` 으로 보임 (깨진 링크는 보통 빨간색) |
| `readlink 링크` | 링크가 가리키는 경로 |
| `find 폴더 -type l` | 모든 심볼릭 링크 |
| `find 폴더 -xtype l` | **깨진** 심볼릭 링크 (따라가 봐도 링크인 것) |
| `ln -s 대상 링크이름` | 링크 만들기 |
| `ln -sfn 대상 링크이름` | 이미 있는 링크를 새 대상으로 바꾸기 |
