# API 서버 상태 점검

이 서버의 `8000` 포트에서 내부 API 가 돌고 있습니다. "어떤 화면은 데이터가 안 나온다"는 제보가 들어왔어요.

## 목표
1. `~/endpoints.txt` 에 적힌 API 주소들을 하나씩 확인해서, **정상 응답(200)이 아닌 주소**를 `~/answer.txt` 에 저장하세요.
2. `http://localhost:8000/api/users.json` 에서 **역할(role)이 `admin` 인 사용자의 email** 을 한 줄에 하나씩 `~/admins.txt` 에 저장하세요. (순서 상관없음)

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `curl 주소` | 응답 본문 보기 |
| `curl -i 주소` | 응답 헤더(상태 코드 포함)까지 보기 |
| `curl -s -o /dev/null -w '%{http_code}\n' 주소` | **상태 코드만** 출력 |
| `curl -s 주소 \| jq .` | JSON 을 보기 좋게 |
| `jq '.[] \| .email'` | 배열의 각 항목에서 email 만 |
| `jq -r '.[] \| select(.role == "admin") \| .email'` | 조건에 맞는 것만, 따옴표 없이(-r) |

> 💡 상태 코드: `200` 정상 · `404` 없는 주소 · `500` 서버 에러 · `401/403` 권한 없음
