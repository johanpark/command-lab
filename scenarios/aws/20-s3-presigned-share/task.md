# 외부 업체에 파일 하나만 하루 동안 공유하기 (S3 미리 서명된 URL)

회계법인에서 **10월 정산 확정본** 파일을 요청했어요. 요청 내용과 보안팀 메모는 `~/request.txt` 에 있어요.

버킷을 공개하면 다른 파일(급여, 계약서…)까지 다 보이고, 외부인에게 AWS 계정을 만들어 주는 것도 과해요.
이럴 때 쓰는 게 **미리 서명된 URL(presigned URL)** 이에요. 내 권한으로 서명한, **그 파일 하나만, 정해진 시간 동안** 열리는 링크예요.

## 목표
1. **10월 정산 확정본** 파일의 미리 서명된 URL 을 만드세요. (초안 말고 확정본!)
2. 유효기간은 **24시간**이에요.
3. 만든 URL 을 **`~/share-url.txt`** 에 한 줄로 저장하세요.
4. 버킷이나 파일을 **공개로 바꾸지 마세요.**

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `aws s3 ls s3://버킷/ --recursive` | 파일 목록 |
| `aws s3 presign s3://버킷/키` | 미리 서명된 URL 만들기 (기본 1시간) |
| `--expires-in 초` | 유효기간 (초 단위, 최대 7일) |
| `curl -s -o /dev/null -w '%{http_code}\n' "URL"` | 링크가 열리는지 확인 (200 이면 OK) |
