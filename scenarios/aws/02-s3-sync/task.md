# S3 에 백업 올리고 웹사이트 동기화하기

S3 버킷 두 개를 관리하게 됐어요. 버킷 이름은 `~/buckets.txt` 에 있어요.

| 버킷 | 용도 |
|---|---|
| `shop-backups-...` | DB 백업 보관 |
| `shop-website-...` | 정적 웹사이트 (버킷 내용이 곧 사이트) |

## 목표
1. **백업**: `~/backup/db-2026-10-29/` 폴더 안의 파일들을 백업 버킷의 **`db/2026-10-29/`** 경로에 올리세요.
   - 예: `~/backup/db-2026-10-29/dump.sql.gz` → `s3://백업버킷/db/2026-10-29/dump.sql.gz`
2. **웹사이트**: `~/site/` 를 웹사이트 버킷과 **똑같이** 맞추세요.
   - 로컬에서 지운 옛 페이지가 버킷에 남아 있으면 안 돼요.
   - `~/site/drafts/` (작성 중인 초안)는 **올리면 안 돼요.**

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `aws s3 ls s3://버킷/ --recursive` | 버킷 안 모든 파일 |
| `aws s3 cp 파일 s3://버킷/경로/` | 파일 하나 올리기 |
| `aws s3 cp 폴더 s3://버킷/경로/ --recursive` | 폴더째 올리기 |
| `aws s3 sync 폴더 s3://버킷/` | 바뀐 것만 올리기 |
| `... --delete` | 로컬에 없는 파일은 버킷에서 지우기 |
| `... --exclude 'drafts/*'` | 빼고 올리기 |
| `... --dryrun` | **실제로 하지 않고** 무엇을 할지만 보기 |
