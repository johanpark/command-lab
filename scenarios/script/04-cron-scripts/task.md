# 파이썬·노드 스크립트를 cron 에 등록하기

`~/jobs` 에 매번 손으로 돌리던 스크립트가 두 개 있어요. 이제 **cron** 으로 자동 실행하려고 해요.

| 스크립트 | 하는 일 | 원하는 실행 시각 |
|---|---|---|
| `~/jobs/cleanup.py` | `~/jobs/tmp` 에서 오래된 임시 파일 지우기 | **30분마다** |
| `~/jobs/daily_report.js` | 일일 보고서를 `$REPORT_DIR` 에 만들기 | **매일 07:30** |

터미널에서는 둘 다 잘 돌아가요.
```
$ cd ~/jobs && python3 cleanup.py
[cleanup] 7일 지난 파일 12개 삭제
$ node ~/jobs/daily_report.js
[report] /home/learner/daily-reports/2026-10-27.txt 작성
```

## 목표
1. `crontab -e` 로 두 스크립트를 위 시각에 등록하세요.
2. 각 스크립트의 출력과 에러를 **`~/jobs/logs/cleanup.log`**, **`~/jobs/logs/report.log`** 에 **이어서**(덮어쓰지 말고) 남기세요.
3. **cron 이 실행하는 환경에서도 성공**해야 해요. cron 은 내 터미널과 다르게 실행된다는 걸 기억하세요.

> 채점할 때 crontab 에 적힌 명령을 **cron 과 같은 환경**(홈 폴더에서, 최소한의 환경 변수로, `sh` 로)에서 직접 실행해 봐요.

> 이 실습 환경에는 cron 이 **실제로 돌고 있어요.** 시각을 잠깐 `* * * * *` (매분)으로 바꿔서 1분 뒤 로그가 쌓이는지 직접 볼 수도 있어요. 확인한 뒤엔 원래 시각으로 되돌리세요!

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `crontab -e` / `crontab -l` | 내 cron 작업 편집 / 보기 |
| `분 시 일 월 요일 명령` | crontab 한 줄 형식 (`*/30 * * * *` = 30분마다) |
| `명령 >> 로그파일 2>&1` | 출력과 에러를 로그 끝에 추가 |
| `cat ~/.bashrc` | 터미널에서만 설정되는 환경 변수 확인 |
| `cd / && env -i HOME=$HOME PATH=/usr/bin:/bin sh -c '명령'` | cron 비슷한 환경에서 시험 실행 |
