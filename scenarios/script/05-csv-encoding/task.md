# 한글이 깨지는 CSV 합치기 (인코딩)

지점 세 곳에서 매출 CSV 를 `~/exports` 로 보내왔어요. 그런데 열어 보니...

```
$ head -2 ~/exports/서울지점.csv
��¥,����,��ǰ,�ݾ�
```

파일마다 저장한 프로그램이 달라서 **문자 인코딩**이 제각각이에요. 한 파일은 윈도우 엑셀에서 저장한 **CP949**(EUC-KR 확장), 다른 파일들은 **UTF-8** 이에요.

## 목표
1. 세 파일을 **하나로 합쳐** `~/report/merged.csv` 로 저장하세요.
   - 머리글(`날짜,지점,상품,금액`)은 **맨 위에 한 번만**
   - 모든 지점의 거래가 빠짐없이 (순서는 상관없어요)
   - **엑셀에서 바로 열어도 한글이 안 깨지게**: **BOM 이 붙은 UTF-8** (`utf-8-sig`) 로 저장
2. 세 지점 **금액 합계**를 `~/answer.txt` 에 숫자로 저장하세요.

## 써볼 명령어
| 명령어 | 하는 일 |
|---|---|
| `file ~/exports/*.csv` | 파일 종류·인코딩 추측 |
| `iconv -f CP949 -t UTF-8 파일` | 인코딩 바꿔서 출력 |
| `head -c 3 파일 \| xxd` | 맨 앞 3바이트 보기 (BOM 이면 `ef bb bf`) |
| `python3` | 대화형 파이썬 |

## 파이썬 한 줄 사전
| 코드 | 뜻 |
|---|---|
| `open(파일, encoding="cp949")` | CP949 로 읽기 |
| `open(파일, encoding="utf-8-sig")` | UTF-8 로 읽기 (앞에 BOM 이 있으면 떼어 줌) |
| `open(파일, "w", encoding="utf-8-sig", newline="")` | BOM 붙은 UTF-8 로 쓰기 |
| `csv.reader(f)` / `csv.writer(f)` | CSV 읽기 / 쓰기 |
